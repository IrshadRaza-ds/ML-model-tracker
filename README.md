# ML Model Tracker API

A simple API to track machine learning models. It gives each model a score and a verdict (Good / Average / Poor).

Built with Python, FastAPI and Pydantic.

## Features
- Add, view, update and delete models
- Sort and search models
- Automatic score and verdict

## How to Run
1. Install: `pip install -r requirements.txt`
2. Start: `uvicorn main:app --reload`
3. Open: http://127.0.0.1:8000/docs
